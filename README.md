# 🤖 Chetak - AI Personal Assistant

Chetak is a Python-based AI personal assistant developed using **Flask, Python, Ollama, OpenCV, HTML, CSS and JavaScript**.

The project provides a web-based chat interface where users can interact with Chetak using text and voice. It also includes features such as **voice interaction, face verification for laptop access, weather information and date/time information**.

---

## 🚀 Features

### 💬 AI Chat
- Chat with Chetak through a web interface.
- Uses a locally running AI model through Ollama.
- Provides natural-language responses.
- Handles general questions and conversations.

### 🎤 Voice Interaction
- Supports voice input.
- Converts spoken input into text.
- Provides voice responses using text-to-speech.

### 👤 Face Verification
- Includes face verification using OpenCV.
- Laptop access can be protected using face verification.
- Uses OpenCV's LBPH Face Recognizer for face recognition.

### 🌦️ Weather Information
- Provides weather information using the Open-Meteo API.
- Retrieves temperature and weather-related information for a location.

### 🕐 Date & Time
- Can provide the current date and time.
- Supports timezone-based time information.

### 🌐 Web Interface
- Built using Flask.
- Provides a simple and interactive chat interface.
- Works through a web browser on desktop and mobile devices.
